## Steps for exporting Gerber and Drill files from Altium \<Eli Williams\>

1. File -> Fabrication Outputs -> Gerber Files

2. Make sure *.gbr is selected (NOT filename.*)

	- The first option on the left

3. Hit apply and save the file to where ever

	- You will not need this file

4. File -> Fabrication Outputs -> NC Drill Files

5. Keep hitting ok until saving the file

6. Save the file where ever

	- You will not need this file

7. Go to your project folder

	- Default:

	- C:\Users\Public\Documents\Altium\<Project Name>

8. Go to the folder labeled "Project Outputs for (Project Name)"

9. Sort by date modified and copy everything that you made recently (within the past couple of minutes)

10. Zip all of the files you selected

11. Send the Zip file to the manufacturer
